# Student Results Summary

A Java console program that analyses a class's marks and prints a summary of how the students performed.

## What it calculates
- Class average
- Number of students who passed and failed (pass mark: 50%)
- Pass rate percentage
- Student with the highest mark
- Number of distinctions (above 75%)
- Average mark of students who passed

## Sample output
​```
The Success Summary!
==========================================================

Average                                  : 61.80
Number Of Students Failed                : 2
Number Of Students Passed                : 3
Pass Rate Percentage                     : 60.00%
Student With The Highest Mark            : Sol, 95
Number Of Students With Distinctions     : 2
Average Mark Of Passing Students         : 83.67

Thank You For Using Our App!
==========================================================
​```

## Built with
- Java
- NetBeans

## How to run
1. Clone the repository or download the code.
2. Open the project in NetBeans (or any Java IDE).
3. Run `SuccessProj.java`.
